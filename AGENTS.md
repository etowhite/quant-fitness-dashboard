# Project instructions

## GitHub updates

- After completing requested project changes and the relevant checks, commit the
  completed changes and push them to the configured GitHub origin. This is a
  standing user instruction; no repeated confirmation is needed.
- Check the resulting GitHub Actions run and report its status. Fix failures
  caused by the changes before declaring publication successful.
- Keep signing keys, credentials, local configuration, build outputs and temporary
  reports out of Git. Publish APKs through the existing release workflow.
- Preserve unrelated or unfinished work, and follow any later user instruction
  that narrows or cancels publication.
