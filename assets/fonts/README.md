# Inter (offline)

Source: https://github.com/rsms/inter/tree/v4.1

`InterVariable.ttf` is the original upright variable font from the v4.1 release.
The four bundled static instances were produced with fontTools 4.68.0:
`opsz=14`, `wght=400/500/600/700`. Only those four instances are declared
in pubspec.yaml and included in the application font bundle.
