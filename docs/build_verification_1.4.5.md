# quant 1.4.5 — кнопки воды, вкладки, отступы рецепта

## Проверенные изменения

- `water_balance_card.dart`: отдельное меню долгого нажатия, тактильный отклик,
  диалог с текущим объёмом, проверка 1–5000 мл и дубликатов, удаление с отменой.
  Короткое нажатие использует прежний слой записи воды. Меню и настройки кнопок
  не изменяют записи Isar. «Свой объём» сохраняет возможность добавить кнопку.
- `water_presets_provider.dart`: теперь сохраняется весь набор кнопок, включая
  стандартные. Старый ключ содержал только дополнительные кнопки: он читается с
  добавлением стандартных. Пустой новый набор остаётся пустым. Изменения
  сериализованы; отмена удаления объединяется с последними настройками.
- `backup_document.dart`: v7 хранит полный набор, v1–v6 импортируются с корректной
  миграцией. Сброс настроек возвращает стандартные три кнопки.
- `dashboard_shell.dart`: убраны полупрозрачность/масштаб/сдвиг всего содержимого
  вкладки. RetainedTabView сохраняет State/скролл, рисует одну непрозрачную страницу,
  выключает тикеры скрытых вкладок. Убрана AnimatedOpacity вокруг BackdropFilter
  островка; скользящее автоскрытие, стекло и анимация индикатора сохранены.
- `recipes_screen.dart`: после поля веса 12 px до кнопки, после кнопки 16 px до
  подписи порций; общий LabeledField сохраняет 6 px до поля. Контурная кнопка с
  внутренними отступами растёт по высоте при переносе длинного текста.
- RU/EN-строки, версия, README и регрессионные тесты обновлены.

## Артефакт изображения: что установлено

Скриншот телефона показывает повторяющиеся фрагменты логотипа и границ. В Dart
не найдено создание копий страниц: исходный IndexedStack рисовал одну вкладку.
Найдена усложняющая композицию комбинация полноэкранных Fade/Scale/Slide и
BackdropFilter под AnimatedOpacity. Flutter
[документирует](https://api.flutter.dev/flutter/widgets/BackdropFilter-class.html)
неожиданные результаты BackdropFilter под Opacity/saveLayer. Это основание
упростить слои, но не доказательство причины именно показанного GPU-артефакта.

Точное воспроизведение на телефоне пользователя недоступно. Widget-тесты
проверяют отсутствие перекрывающихся исходящих страниц, сохранение состояния и
скролла, отключение скрытых тикеров и быстрые переключения. Android integration
дополнен 16 переключениями без ожидания завершения анимации. Для окончательного
подтверждения устранения следов нужен повторный тест APK на исходном телефоне;
рендерер Impeller и настройки GPU без такого подтверждения не менялись.
