# Проверка quant 1.4.0 (versionCode 5)

## Изменения

- Health Connect: независимые READ-права, повторный запрос недостающих прав по
  кнопке синхронизации и Pull-to-Refresh, без предпочтений брендов.
- Шаги: системный агрегат, затем raw STEPS при null/0/ошибке. Сырые данные проходят
  removeDuplicates, пересечения разделяются на интервалы без сложения конкурирующих
  устройств; это оценка, системные приоритеты остаются у основного агрегата.
- Калории: ACTIVE_ENERGY_BURNED, затем TOTAL_CALORIES_BURNED при отсутствии/нуле.
  Общие калории подписаны отдельно, включая основной обмен.
- local_auth: системная биометрия или ПИН/пароль, подтверждение включения/отключения,
  блокировка холодного запуска и после минуты в фоне; gate расположен над Navigator.
  Отмена/ошибка аутентификации не открывает содержимое. БД дополнительно не шифруется.
- Единые контуры 1 px: light #D0D5DD, dark/AMOLED #2E2E36. Карточки radius 24,
  капсулы, поля, разделители, кнопки и плавающая панель используют общую тему.
- Плавающая навигация сохраняет состояние вкладок и плавно меняет содержимое.
  Анимируются размеры карточек питания, счетчики/прогресс, шаги онбординга и форма еды.
- Шесть основных палитр в два ряда; старые значения палитр читаются из бэкапов.
- Вода: ручной ввод 1–5000 мл и до восьми дополнительных быстрых кнопок.
  JSON v5 включает кнопки; импорт v1–v4 поддержан. App lock привязан к устройству
  и не включается автоматически при импорте копии.
- Автоматический локальный + онлайн-поиск, debounce 350 мс. Ограничение OFF
  10 запросов/мин сохранено, поэтому повторный запрос может ждать свободного слота.
- Штрихкод сразу открывает камеру; есть рамка, фонарик и ручной ввод, доступный
  также при отказе разрешения камеры. Кадры не сохраняются/не отправляются.

## Пройдено локально

- Flutter 3.35.7 / Dart 3.9.2, Java 17, Android SDK 35, minSdk 26.
- `flutter analyze --fatal-infos`: No issues found.
- `flutter test`: **54 теста прошли**, включая реальный Isar Core на Windows.
- Проверены fallback null/0, пересечения и границы дня, приоритет рабочего агрегата,
  общие/активные калории, частичные разрешения, блокировка/отмена/возврат из фона,
  вода и JSON v5, навигация на 320/390 px, контуры light/dark/AMOLED.
- Превью онбординга и настроек на ширине 390 px с локальными Inter/Material Icons:
  без исключений и переполнений; изображения в `docs/screenshots/`.
- OSV: 124 точные Pub-версии, 0 advisory-совпадений; source security regression
  checks пройдены. Это не полный аудит Maven/NDK или физического устройства.

кодогенерация и публикация также прошли в

повторный прогон завершился успешно без изменения кода приложения.

- [Скачать quant 1.4.0](https://github.com/etowhite/quant-fitness-dashboard/releases/tag/v1.4.0).

Физическая биометрия/ПИН, камера, доставка уведомлений и выгрузка данных конкретными
устройствами требуют проверки на телефоне.

Без `android/key.properties` используется debug-подпись. Ключ CI может отличаться
между сборками и от локального ключа. Если Android откажет в обновлении из-за
подписи, сначала экспортируйте JSON в установленном приложении, затем переустановите
APK и импортируйте копию. Для постоянных обновлений нужен постоянный release keystore.
