# Дашборд — этап 4

`DashboardScreen` подключен в `dashboard_shell.dart`. Для этой вкладки shell
не рисует дополнительный AppBar: дата и кнопка синхронизации находятся внутри
общего прокручиваемого экрана. RefreshIndicator работает и на коротком экране.

Виджеты в `features/dashboard/presentation/widgets/`:

- DashboardHeader: русская дата, кнопка и индикатор синхронизации.
- HealthAccessBanner: подключение, отсутствие HC или необходимость обновления.
- NutritionSummaryCard: круг калорий и три шкалы БЖУ из дневника Isar.
- HealthMetricsGrid: две карточки HC; на очень узком экране или крупном шрифте
  располагаются вертикально, чтобы текст помещался.
- WeightChartCard: плавная линия, подсвеченные точки, градиент и tooltip.

Нормы по умолчанию: 2200 ккал, 150/70/250 г БЖУ, 10 000 шагов. Кольцо и шкалы
ограничены диапазоном 0–1, превышение калорий выводится словами. Пустой дневник
означает нулевое потребление; ошибка БД показывается отдельно и не заменяется
нулями. Питание не зависит от наличия разрешений Health Connect.

Health Connect читается через dailyHealthProvider. При обновлении сохраняется
предыдущий снимок; при ошибке показано уведомление и время получения снимка.
Источники в карточках Mi Fitness/Picooc — подсказки предполагаемого сценария,
данные по-прежнему читаются из всех источников Health Connect.
Дельта веса рассчитывается по предыдущему по времени измерению в доступной
30-дневной истории. Вес и процент жира могут иметь разные даты — они подписаны.

Для графика нужны две разные временные точки. Некорректные значения веса
исключаются, одинаковые timestamp объединяются, точки сортируются. Ось X
использует реальные интервалы времени; для измерений внутри одних суток
подписи показывают время. Для постоянного веса диапазон Y расширяется.

Таймер переключает дату дневника в локальную полночь; возврат в приложение
перепроверяет дату и запускает обновление. До получения нового снимка
вчерашние шаги/калории не показываются под сегодняшней датой.
Русские данные intl инициализируются в main до runApp.

В проекте по-прежнему находятся заглушки Isar `.g.dart`: сначала выполните
генерацию по local_database.md. Затем:

```sh
dart format lib test
flutter analyze
flutter test
flutter run
```

Добавлены проверки порядка/дедупликации веса, дельты, пустого и плоского
графика, ограничения прогресса при превышении нормы и сохранения снимка при
ошибке синхронизации. Flutter SDK отсутствует в текущем окружении:
анализатор, тесты и визуальная проверка на устройстве не запускались.
