# Замеры и цели — этап 6

MeasurementsScreen заменил третью вкладку. Включает дневные цели, сетку
последних объемов, ввод/дополнение замера, график и удаление записей истории.

## Цели

UserGoals хранит калории, БЖУ и шаги. Нормы по умолчанию: 2200/150/70/250,
10 000 шагов. SharedPreferences 2.2.3 выбран для совместимости с базовым
Dart constraint проекта. Все цели записываются одним JSON по ключу
user_goals.v1; новых коллекций и схем Isar не требуется.

userGoalsProvider (AsyncNotifier) загружает и сохраняет цели.
effectiveUserGoalsProvider предоставляет их дашборду и питанию; до загрузки
используются defaults, при ошибке записи — последний подтвержденный снимок.
Карточка целей показывает ошибки и позволяет повторить загрузку или исправить
сохраненные нормы вручную. Успех сохранения обновляет все подписанные экраны.
Все цели должны быть конечными числами больше нуля; шаги — целое число.
Поддерживаются точка и запятая для калорий/БЖУ. Исторические КБЖУ не меняются:
для сравнения любого дня применяется текущая цель пользователя.

## Замеры

Каждый параметр независимо ищет два последних непустых значения. Поэтому
запись только талии не скрывает последний известный объем груди. Дельта —
последнее минус предыдущее значение в см; дата подписана отдельно для каждого
параметра. Цвет дельты не является оценкой улучшения или ухудшения.

Форма открывается на сегодня. При выборе даты загружается существующая запись
этого дня. Можно заполнить часть полей и/или заметку; полностью пустая форма
не сохраняется. Числа должны быть положительными и конечными. При ошибке
загрузки запись блокируется, чтобы не затереть существующие данные случайно.
Повторное сохранение того же дня заменяет запись с сохранением id. Поля,
очищенные пользователем, становятся null. Заметка ограничена 2000 символами.

График переключается между четырьмя параметрами. Общий TimeSeriesChartCard
используется также для веса на дашборде: плавная неоновая линия, точки,
градиент, реальные интервалы времени и корректный диапазон постоянных значений.
Меньше двух разных временных точек — отдельное пустое состояние.

История отсортирована от новых записей к старым. Удаление требует подтверждения
даты и удаляет все поля записи. Watchers обновляют график, карточки и историю.
Сервис дополнен getBodyMeasurementForDay и deleteBodyMeasurement.

## Проверка

Добавлены тесты defaults, сохранения/повторного чтения целей, восстановления
после поврежденного JSON, ошибки записи и валидации. Тесты замеров проверяют
частичные записи и дельту по нужному параметру; интеграционный тест расширен
чтением по дню и удалением замера. Предыдущие тесты графика теперь проверяют
общий компонент через WeightChartCard.

После генерации Isar по local_database.md и установки Flutter:

```sh
flutter pub get
dart format lib test integration_test
flutter analyze
flutter test
flutter test integration_test/local_database_test.dart -d <android-device-id>
flutter run
```

В текущем окружении Flutter/Dart отсутствуют: тесты, анализатор и визуальная
проверка не запускались. Для Android все еще нужен Gradle runner по README.
