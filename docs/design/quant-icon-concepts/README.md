# quant — варианты иконки

Этап выбора дизайна. Ресурсы Flutter и Android не заменены.

- 01-fluid: Плавная q — текучая дуга с мягким переходом в хвост.
- 02-motion: Движение — наклонная форма с переменной толщиной и упругим поворотом.
- 03-geometric: Геометричная q — круговая основа и постоянная толщина 13/108.

Знак: #B4A0E5 (AccentPalette.lavender из проекта). Фон: #121212 (AppColors.background).

В каждой папке: mark.svg без фона, SVG и PNG 512 px в трех сочетаниях, PNG 16/24/32/48/64 px, preview.svg и preview.png.

comparison.png и comparison.svg — общее сравнение. Все изображения получены из одних и тех же векторных контуров; силуэт при инверсии одинаков.

Круглая, квадратная и скругленная маски показаны для визуальной проверки полей. Это концепты: финальные адаптивные Android-слои и проверка launcher будут подготовлены после выбора.

Сборка превью: node generate.cjs (использует sharp из bundled Node runtime).
