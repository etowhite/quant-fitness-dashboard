# quant — Плавная q

Выбран вариант 01. Знак #B4A0E5, фон #121212.

## Источник и обновление ресурсов

`tool/generate_quant_brand.cjs` содержит геометрию выбранного варианта, толщины
и цвета. Генерирует SVG, Android VectorDrawable, Flutter Path и растровые
launcher-иконки. Для запуска нужны Node.js и sharp, доступный через node_modules
или NODE_PATH. Команда: `node tool/generate_quant_brand.cjs`.

Финальный контур состоит из 38 кубических сегментов с круглыми окончаниями.
Плавное изменение толщины сохранено; исходный знак не заменен обводкой
постоянной толщины. Максимальная погрешность подбора кривых на контрольных
точках — 0,008 единицы на холсте 108 × 108.

## Подключенные ресурсы

- `assets/branding/quant-mark.svg`: знак с прозрачным фоном.
- `assets/branding/quant-logo.svg`: знак на скругленной темной подложке.
- `assets/branding/quant-mark-monochrome.svg`: белый знак без фона.
- Android: отдельные векторные foreground/background/monochrome; обычная и
  круглая adaptive icon для API 26+ и monochrome для API 33+.
- PNG обычной и круглой launcher-иконки: mdpi–xxxhdpi, 48/72/96/144/192 px.
- `android:roundIcon` подключен в manifest.
- Splash: векторный знак и темный фон до Android 12 и системный splash в
  Android 12+, включая ночную тему.
- Flutter: `QuantLogoPainter` использует сгенерированный `quant_mark_path.dart`.
  Этот общий виджет используется в «О приложении», заголовке, отчетах,
  onboarding и экране блокировки. Обновлено описание для доступности RU/EN.
- Значок уведомлений приведен к тому же монохромному силуэту.

## Проверка полей

Фон adaptive icon занимает 108 × 108. Контур масштабируется на 2/3 вокруг
центра (54, 54). При системном окне 72 × 72 знак сохраняет пропорции выбранного
превью. Максимальный радиус контура после масштабирования — 29,3047 dp;
запас до границы безопасного круга диаметром 66 dp — 3,6953 dp.

`preview.png` показывает центральное системное окно adaptive icon под круглой,
квадратной и скругленной масками, а также тематическую окраску и размеры
16–64 px. Тематическая палитра иллюстративная: реальные цвета выбирает Android.
`geometry.json` содержит результат проверки контура. Подключенного Android-
устройства при проверке не было; превью масок получены из геометрии ресурсов.

Требования Android: [adaptive icons](https://developer.android.com/develop/ui/views/launch/icon_design_adaptive),
[splash screen](https://developer.android.com/develop/ui/views/launch/splash-screen).
