# Питание — этап 5

NutritionScreen подключен ко второй вкладке. Выбранная дата сохраняется при
переключении вкладок; стрелки используют календарные дни. Нажатие даты
открывает стандартный DatePicker. Формат даты русский; язык встроенного
календаря определяется MaterialLocalizations приложения.

Сводка показывает съеденное / норму: 2200 ккал, 150/70/250 г БЖУ, как на
дашборде. Четыре секции показывают порции и суммы калорий за прием пищи.
Свайп влево удаляет запись только после успешной транзакции; Isar watcher
обновляет список и сводку. При ошибке строка остается, отображается SnackBar.
«Отменить» восстанавливает снимок записи с новым id в исходную дату и прием
пищи. Отмена доступна, пока показан соответствующий SnackBar.

Окно AddFoodSheet открывается кнопками секций и FAB. При открытии из секции
прием пищи уже выбран; в окне его можно изменить. FAB начинает с «Завтрак».
Дата фиксируется при открытии окна, поэтому запись не попадет в другой день.
После сохранения окно закрывается, watchers обновляют питание и дашборд.

Поиск с задержкой 180 мс использует регистронезависимый префиксный индекс
Isar, показывает до 30 продуктов. Подписка autoDispose реагирует на изменения
справочника и отменяется после закрытия окна/выбора продукта.
Форма своего продукта находится в том же окне. После сохранения в Isar
продукт сразу выбран, но в дневник попадает только после подтверждения порции.
Граммовка по умолчанию 100 г; чипсы 50/100/150/200/250 г пересчитывают
предпросмотр. При сохранении расчет выполняется сервисом по той же формуле.

Валидация принимает десятичную точку и запятую, запрещает пустые поля,
отрицательные, NaN и бесконечные значения; порция должна быть больше нуля.
Повторные нажатия сохранения блокируются. Все данные сохраняются локально,
HTTP-запросов модуль не выполняет.

Основные файлы:

- presentation/nutrition_screen.dart
- presentation/widgets/{daily_nutrition_summary,meal_section_card,add_food_sheet,create_product_form}.dart
- presentation/nutrition_input.dart
- application/product_search_provider.dart

Пути относительно lib/features/nutrition. Сервис дополнен watchProducts.
Новых пакетов и изменений схем Isar в этом этапе нет.

Проверки добавлены в nutrition_input_test.dart и nutrition_widgets_test.dart:
валидация чисел, выбор продукта и приема пищи, предпросмотр порции с запятой,
быстрая граммовка и отклонение некорректного нового продукта.

Перед проверкой выполните генерацию заглушек Isar по local_database.md, затем:

```sh
dart format lib test
flutter analyze
flutter test
flutter run
```

Flutter/Dart в окружении отсутствуют, поэтому тесты, сборка и визуальная
проверка не запускались. Также пока требуется Android Gradle runner (README).
